Frequently Asked Questions (FAQ)

Can I export an image with a transparent background?

Yes. Select PNG as your output format and check "Transparent Canvas Background". Any element without an explicit background color will render transparently.

Why use 2x Retina scale?

2x scaling produces twice the physical pixel count of the CSS dimensions, eliminating fuzzy borders and pixelated text on high-density displays.

Are web fonts from Google Fonts supported?

Yes. You can import fonts directly using <link> tags or @import inside a <style> block within your snippet.

Is my code or graphic uploaded to a remote server?

No. EasyToolz executes all rendering locally within your web browser sandbox. No source code or generated graphics are stored or transmitted.
